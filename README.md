# Einleitung

Kleinere Version der Original Campuswochen Wortuhr. 
Das Buchstabenlayout dieser WortUhr ist angelehnt an das Layout, welches von Frank Meyer verwendet wird.

Der Aufbau ist nun kompatibel mit 60 LED/m WS2812B/SK6812 LED Streifen. Um das zu erreichen ist die Rahmengröße reduziert auf 35cm Innenmaß. Hierzu eignet sich zum Beispiel der IKEA SANNAHED 35x35cm Rahmen. Die Steuerplatine ist auf das wesentliche beschränkt, die Stromversorgung übernehmen zwei generische DCDC Mini-560 Netzteile. Es wird weiterhin über einen Rundbuchsenanschluss mit 19-21V eingespeist. Um die Bestellung möglichst einfach zu gestalten werden die Power und Steuerplatine auf eine gemeinsame Platine gepaneled. (Siehe Kombiplatine THT)

![Kombilatine](https://raw.githubusercontent.com/RT-CUSTOMZ/wortuhr-mini/refs/heads/main/Bauanleitung/FullView.png)

Die Software und das Layout der Matrix von Frank Meyer wurden minimal angepasst.
